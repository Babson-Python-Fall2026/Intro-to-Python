Purpose

This exercise is practice, not a speed test. The goal is to show that you can predict Python behavior, explain what happened, investigate surprises, and combine basic ideas into a small solution.

When a question says predict first, write down your prediction before you run the code. If your prediction is wrong, do not erase it. Record what actually happened and explain what changed in your understanding.

How to complete the exercise

  1. Place the supplied homework.py file in the same assignment folder as this HTML file.
  2. Open homework.py in VS Code.
  3. Each question is already placed inside a function such as question_a1(). The functions are supplied only to keep the questions separate. You are not being tested on writing functions yet.
  4. Complete all predictions, explanations, and written answers as Python comments in the places provided.
  5. Write your Python code only where the starter file says YOUR CODE or where a question asks you to modify existing code.
  6. At the bottom of homework.py, uncomment the function call for the question you are currently working on. Run one question at a time.
  7. Do not remove the instructor's headings, starter code, or instructions unless a question specifically tells you to change something.
Important: If your original prediction is wrong, leave the prediction in the file. Add an Actual result and an explanation underneath it. An incorrect prediction followed by a good explanation demonstrates learning.

AI use for this exercise

You may use your OIM3600 Project AI as a Python reference. For example, you may ask:

  • “How do I add an item to a list?”
  • “What does sorted() return?”
  • “How do I slice the first three items?”
  • “What does .strip() do?”

You may not ask AI to design or solve a question for you. The reasoning, choices, explanations, and final design must be yours.

If AI supplies syntax, you are still responsible for understanding why it works and deciding whether it belongs in your solution.

Part A

Predict Before You Run

Write your prediction in homework.py before running the code.

20 points

A1 — Types and operations

x = "7"
y = 3

print(x + str(y))
print(x * y)
print(type(x))
print(type(y))
  1. Predict all four outputs before running the code.
  2. Run it. If anything surprised you, explain why.

A2 — Strings, indexing, and slicing

text = "Babson College"

print(text[0])
print(text[-1])
print(text[1:6])
print(text[:6])
print(text[::-1])
  1. Predict each output.
  2. Which expression creates the largest new string?
  3. Explain the difference between indexing and slicing in one sentence.

A3 — Lists and sorting

numbers = [4, 1, 3, 2]
ordered = sorted(numbers)

print(numbers)
print(ordered)
  1. Predict both outputs.
  2. Does sorted(numbers) change numbers? Explain.
Part B

Investigate a Bug

Use small experiments instead of guessing.

20 points

B1 — Why did the list disappear?

items = [3, 1, 2]

items = items.sort()

print(items)
  1. Predict first: What do you expect this to print?
  2. Run it.
  3. Use type() in a small experiment to investigate what happened.
  4. Rewrite the code so that items becomes [1, 2, 3].
  5. Write a second correct version that leaves items unchanged and stores the sorted result in a new variable.
Evidence required: keep your small investigation in homework.py. Do not submit only the final fix.
Part C

Modify Existing Data

Use the tools from Sections 1–6 deliberately.

25 points

C1 — Sales list

sales = [1240.50, 875.25, 1920.00, 650.75, 1435.50, 990.00]

Write code that does all of the following:

  1. Creates a new list called ordered_sales containing the sales from largest to smallest.
  2. Leaves the original sales list unchanged.
  3. Creates top_three containing only the three largest sales.
  4. Creates sale_count containing the number of sales.
  5. Prints the three variables clearly using f-strings.

Then answer in comments:

  1. Why does your code not change sales?
  2. Which line creates a new list by sorting?
  3. Which line creates a new list by slicing?
A complete explanation should recognize that sales is neither modified nor reassigned.
Part D

Build a Small Sales Snapshot

Combine strings, lists, indexing, slicing, sorting, and f-strings.

25 points

D1 — Starter data

report_name = "  september sales  "
region = "Boston"
sales = [1240.50, 875.25, 1920.00, 650.75, 1435.50, 990.00]

Create a small report that prints something similar to:

SEPTEMBER SALES — Boston
Number of sales: 6
Largest sale: $1,920.00
Smallest sale: $650.75
Top three: [1920.0, 1435.5, 1240.5]

Your program must:

  1. Remove the extra spaces from report_name.
  2. Display the report name in uppercase.
  3. Create a new descending sorted list without changing sales.
  4. Use indexing to obtain the largest and smallest sale from the sorted list.
  5. Use slicing to obtain the top three.
  6. Use len() for the number of sales.
  7. Use f-strings for the printed report.
  8. Add one additional useful line of information of your own choosing using only ideas from Sections 1–6.
Do not use a loop. Loops have not been assigned yet. Solve this using only material from Sections 1–6.
