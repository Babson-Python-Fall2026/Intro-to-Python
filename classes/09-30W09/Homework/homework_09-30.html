Problem 1 · Copies and imports

Predict~10 min10 pts

A manager keeps a dictionary of team rosters and makes two backups before editing it.

import copy

teams = {"sales": ["Ana", "Ben"], "ops": ["Cy"]}
shallow = teams.copy()
deep = copy.deepcopy(teams)

teams["sales"].append("Dee")
teams["ops"] = ["Eve"]

print("shallow:", shallow)
print("deep:", deep)
print(teams["sales"] is shallow["sales"])
print(teams["ops"] is shallow["ops"])
  1. Before running, fill in the # Prediction: lines for all four printed lines.
  2. Run it and record the # Actual: output.
  3. # Explanation: shallow picked up "Dee" but did not pick up ["Eve"]. Why does one change show up in the shallow copy and the other doesn't? Use the words mutate and rebind in your answer.
  4. Rewrite just the import and the deepcopy line two more ways: once using from copy import deepcopy, and once using an alias of your choice (import copy as ...). Show that each version still produces the same deep result.

Problem 2 · Boolean logic and De Morgan

PredictWrite~15 min10 pts

A lender is screening a loan applicant.

credit_score = 690
income = 72000
has_cosigner = True
debt_ratio = 0.35

print(credit_score >= 700)                                     # 1
print(income > 50000 and debt_ratio < 0.4)                     # 2
print(credit_score >= 700 or has_cosigner)                     # 3
print(not has_cosigner)                                        # 4
print(not credit_score >= 700 and income > 50000)              # 5
print(not (credit_score >= 700 and income > 50000))            # 6
print(credit_score >= 650 and income > 80000 or has_cosigner)  # 7
print(600 <= credit_score < 700)                               # 8
  1. Predict True or False for all eight lines, then run and compare.
  2. Lines 5 and 6 look almost the same. Explain why they can give different results in general, even if they happen to match here. Find values of credit_score and income that make lines 5 and 6 disagree.
  3. Line 7 mixes and and or with no parentheses. Which one does Python evaluate first? Rewrite line 7 with parentheses that make that order explicit.
  4. The lender rejects an application when not (good_credit or has_cosigner). Use De Morgan's law to rewrite this condition with no not in front of the parentheses.
  5. Prove your rewrite is correct: write nested for loops over [False, True] for good_credit and has_cosigner that print both the original expression and your rewrite for all four combinations.
