Core notes

  • A variable gives a name to a value so you can refer to that value later.
  • Use the assignment operator =: age = 20.
  • Text values are strings and are written inside quotation marks.
  • Python supports multiple assignment: several variables can receive different values in one statement.
  • Python also allows chained assignment when several variables receive the same value.

Code to remember

age = 20
sentence = "My name is Avi"

sarah, bob, mike = 16, 21, 17
sarah = bob = mike = 17

Variable = a name for a stored value. = assigns. Strings need quotes. Python can assign several variables at once.

Core notes

  • range() lets a loop iterate through a sequence of numbers.

Core notes

  • Inheritance lets a new class reuse features from an existing class.
  • The video uses Car as a parent class and a sports-car class as a child.
  • super().__init__() calls the parent initialization so inherited attributes are set up.
  • The child class can add new attributes or replace inherited attribute values.
  • If the child defines a method with the same name as the parent's method, the child's version runs; the video calls this overriding.
  • The stated benefits are code reuse, easier maintenance, and a logical organization of related classes.

Code to remember

class Car:
    def __init__(self):
        self.wheels = 4
        self.seats = 5

    def drive(self):
        print("Driving a car")

class SportsCar(Car):
    def __init__(self):
        super().__init__()
        self.engine_power = "400 hp"
        self.seats = 2

    def drive(self):
        print("Driving a sports car")
A GOOD STUDENT NOTE MIGHT LOOK LIKE THIS

Inheritance = child class reuses parent class behavior/data. super() reaches the parent. Redefining a method in the child overrides the parent's version.
