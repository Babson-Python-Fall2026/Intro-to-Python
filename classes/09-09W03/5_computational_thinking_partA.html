02 · A classroom simplification

Turing machine primitive operations

#ActionMeaning
1Go leftMove the head one square left.
2Go rightMove the head one square right.
3ScanRead the symbol in the current square.
4Print / writeWrite a symbol; writing a blank erases.
5Choose the next instructionFollow a rule based on the symbol and control state.
6StopHalt the computation.

This is a teaching summary, not a uniquely defined list of “Turing’s six instructions.” Formal models group these actions differently. Moving along the tape is not necessarily fetching the next instruction. Source: Turing, §§1–3

03 · An important boundary

Powerful does not mean unlimited

A universal machine can perform any Turing-computable task, given enough time and memory.

Not every problem is computable

Some problems have no algorithm that solves every case.

Computable does not mean practical

A solution may require more time or memory than we can afford.

The Church–Turing thesis connects this formal model to the intuitive idea of an effective algorithm. Source: Turing, §§8–11

06 · Objects and variables

Everything in Python is an object

A class defines a type of object, such as a student, integer, or list. An object is an instance of a class.

Objects have:

  • Attributes — data associated with the object.
  • Methods — operations associated with the object’s type.

For example, a Student object might have:

AttributesMethods
NameEnroll in a course
GradeUpdate a grade

Variables are names or labels that refer to objects.

student = Student("Bob")

Student is the class. Student("Bob") creates an object. student is the variable referring to it.

07 · Objects, variables, and types

Which objects can change?

Variables are names / labels that refer to an object.

Primitive (basic) types

TypeCan the object change?
Integer intImmutable

Collections

TypeCan the object change?
List listMutable

Mutable: the object can change.
Immutable: the object cannot change; a variable can still be reassigned.

A tuple can contain a mutable object, such as a list, whose contents can change. Source: Python data model

08 · Predict before running

Similar code, different outcomes

An integer

a = 5
b = a
a += 1
print("a =", a)
print("b =", b)

A list

a = [5]
b = a
a += [1]
print("a =", a)
print("b =", b)
After the code runsInteger exampleList example
a refers to6[5, 1]
b refers to5The same list: [5, 1]
Reveal the explanation

Integer addition returns a different integer. List += extends the existing list. Both assign the result back to a; for the list, that result is the same object.

09 · Computational thinking with AI

AI can write code. We must judge it.

Knowing the building blocks lets us ask precise questions about an AI-generated program.

LensQuestions for any program
InputsWhat information is needed? What inputs are valid?
StateWhat does the program remember, and what does each value mean?
TransitionsWhat rules change the state, and in what order?
InvariantsWhat must remain true as the program runs?

Ask AI for an explanation. Check it with normal cases, boundary cases, and invalid inputs.

10 · Computational thinking

Four tools for computational thinking

ToolWhat we doQuestion to ask
AbstractionRepresent the essential features and hide details we do not need.What matters for this task?
DecompositionBreak a problem into smaller, manageable parts.What smaller tasks make up the whole?
Pattern recognitionLook for similarities, repeated structures, and reusable ideas.Have we solved something like this before?
AlgorithmsSpecify precise steps, decisions, and repetitions to solve a problem.What exactly happens, and in what order?

Use these tools to develop a solution. Use inputs, state, transitions, and invariants to describe and check how it works.

These tools work together; they are not a rigid sequence. Abstraction chooses what to expose or hide. Decomposition divides the work.

11 · The central idea

The challenge is how we combine them

Simple operations do not make
every problem simple.

The hard work is choosing a representation, specifying the rules, and checking that the result is right.

Python gives us the building blocks.
AI helps us assemble them.
Computational thinking helps us decide what to build—and whether it works.
