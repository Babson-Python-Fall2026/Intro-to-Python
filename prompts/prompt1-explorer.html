Prompt 1 of 3

The Explorer

Your first AI prompt. Simple, focused, and built around one idea: never accept the first answer.

Introduced: Classes 2–12 — AI Workbook, then Python Foundations Workbook

Why This Prompt, Why Now

In the first weeks of the course you are learning Python syntax and basic programming concepts. You do not yet have the vocabulary for design methodology — inputs, state, transitions, invariants. That comes later.

What you can learn right now is the most important habit of all: curiosity. The Explorer prompt builds four habits that will stay with you through every subsequent prompt and every AI interaction you have in this course.

What this prompt introduces
  • Ask why — never accept code you cannot explain
  • Demand simplicity — always ask for the beginner solution first
  • Request alternatives — there is almost always another way
  • Workbook constraint — all code stays within course concepts
Before you use this prompt

Upload the Foundations of Programming in Python workbook to your AI chat — or use your Claude Project where it is already uploaded. This tells the AI which Python concepts are in scope for this course.

The Four Habits

This prompt is built around four habits. Learn these now. They will still be active in Prompt 3 through the final exam.

Habit 01

Ask Why

After every answer, ask why it works. If you cannot explain the code, you do not own it yet. A correct answer you cannot explain is not useful.

Habit 02

Demand Simplicity

AI defaults to more complex solutions than necessary. Always ask: is there a simpler beginner-level way? The simplest correct solution is always the best starting point.

Habit 03

Request Alternatives

The first approach AI gives you is not the only approach. Ask for two or three different ways. Understanding multiple solutions deepens your understanding of each one.

Habit 04

Stay in Scope

AI should introduce only concepts covered in the Python workbook. If you explicitly introduce a concept you already know and want to use, AI may work with it. Otherwise, if AI uses something you have not learned yet, ask for a version using only what you know.

The Prompt

Copy and paste this prompt at the start of any AI conversation about Python in this course. Replace [PASTE YOUR QUESTION HERE] with your actual question or problem.

Prompt 1 — The Explorer
I am a student in a beginner Python course called Computational Thinking with AI and Python. I have uploaded the Foundations of Programming in Python workbook to this chat. Use that workbook to determine which Python concepts I have been taught so far. Rules for this conversation: 1. Use Python concepts covered in the uploaded workbook unless I explicitly introduce a concept I already know and ask to use it. If a simpler solution exists using concepts I have learned, always prefer it. If you think a concept outside the workbook would be useful, do not introduce it unless I ask about it. 2. Do not just give me the answer. After every piece of code or explanation, ask me: - Do you understand why this works? - Can you explain what each part does? If I cannot explain it, help me understand before moving on. 3. Always check for simplicity. After giving any solution, ask: - Is there a simpler beginner-level way to solve this? - Does this use more code or more complex structures than necessary? If yes, show me the simpler version. 4. Always offer alternatives. After giving a solution, briefly describe one or two other approaches. Explain the tradeoff: why would someone choose one over the other? 5. Keep me in charge. Do not solve the whole problem for me at once. Ask me what I have tried first. Ask me what part I am stuck on before writing any code. 6. Do not add comments to code you generate for me. I will write the comments myself to demonstrate that I understand the code. If I show you my own comments, you may review them and tell me whether they accurately explain the code. Here is my question or problem: [PASTE YOUR QUESTION HERE] Start by asking me what I have already tried.

How to Use This Prompt

The prompt does most of the work for you — but only if you engage with the questions AI asks back. Here is what to expect and how to respond.

What AI will do

Expected AI behavior with this prompt

AI will ask what you have already tried before giving any code. After giving code it will ask if you can explain it. It will check whether a simpler solution exists. It will offer at least one alternative approach. If any of these don't happen, remind AI of the rules in the prompt.

What you should do

Your job in the conversation

Answer the questions AI asks back — don't skip them. When AI asks "can you explain what this does?", actually try to explain it. That explanation is where the learning happens. If you cannot explain a line of code, that is valuable information: it means you need to ask more questions before moving on.

When the prompt is working

You will know the prompt is working when you feel slightly challenged by the conversation — when AI asks you something you have to think about before answering. If every AI response just gives you what you asked for with no pushback, check that you pasted the full prompt correctly.

Use this prompt with a Python problem from the workbook. After the conversation, write down one thing the AI asked you that you had to actually think about.
